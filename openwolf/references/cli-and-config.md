# CLI and Config Reference

## CLI Commands

### Core Commands

#### `openwolf init`
Initialize OpenWolf in the current project directory.

- Creates `.wolf/` directory and all state files
- Scans project, generates `anatomy.md`
- Registers six hooks in `.claude/settings.json`
- Idempotent: safe to run again; merges hooks rather than overwriting

```bash
openwolf init
```

#### `openwolf status`
Show health summary: hook registration status, file integrity check, session stats, anatomy coverage, and token ledger totals.

```bash
openwolf status
```

#### `openwolf scan`
Refresh `anatomy.md` by re-scanning the project filesystem. Use after adding many files or when anatomy feels stale.

```bash
openwolf scan
openwolf scan --check    # Exit code 1 if anatomy is stale vs filesystem (useful in CI)
```

#### `openwolf dashboard`
Start the real-time web dashboard at `http://localhost:18791`. Displays session token usage, anatomy coverage, and cerebrum entries.

```bash
openwolf dashboard
```

Port is configurable via `config.json` (`dashboardPort`).

---

### Daemon Commands

The optional daemon handles background cron tasks, file watching, and dashboard serving. Requires PM2 or runs as a direct fork.

```bash
openwolf daemon start    # Start the background daemon
openwolf daemon stop     # Stop the daemon
openwolf daemon restart  # Restart the daemon
openwolf daemon logs     # Tail daemon logs
```

Install PM2 for reliable background operation: `npm install -g pm2`

---

### Cron Commands

Manage scheduled tasks defined in `cron-manifest.json`.

```bash
openwolf cron list          # List all scheduled tasks and their last run status
openwolf cron run <id>      # Manually trigger a cron task by ID
openwolf cron retry <id>    # Retry a failed task from the dead-letter queue
```

Default cron tasks included:
- Anatomy rescan every 6 hours
- Weekly AI cerebrum reflection (review and prune stale entries)
- Weekly token usage report generation

---

### Bug Memory Commands

Search the structured bug fix log.

```bash
openwolf bug search <term>    # Search buglog.json by error message, tag, or description
```

Example:
```bash
openwolf bug search "cannot read properties"
openwolf bug search "null-check"
```

---

### Maintenance Commands

```bash
openwolf update            # Update OpenWolf hooks across all projects
openwolf restore           # Restore .wolf/ from most recent timestamped backup
openwolf restore <backup>  # Restore from a specific backup timestamp
```

`openwolf update` is useful after upgrading the npm package — refreshes hook scripts without resetting learned memory.

---

### Design QC Command

Capture full-page screenshots for design review (requires puppeteer-core).

```bash
openwolf designqc
```

Auto-detects the dev server URL, captures viewport-height JPEG sections at:
- Desktop: 1440×900
- Mobile: 375×812

Saves captures to `.wolf/designqc-captures/` and metadata to `.wolf/designqc-report.json`.

## config.json Schema

Located at `.wolf/config.json`. Generated by `openwolf init` with sensible defaults.

```json
{
  "dashboardPort": 18791,
  "exclude": [
    "node_modules",
    ".git",
    "dist",
    ".next",
    "build",
    "coverage",
    ".wolf"
  ],
  "cronSchedules": {
    "anatomyScan": "0 */6 * * *",
    "cerebrumReflection": "0 9 * * 1",
    "tokenReport": "0 9 * * 1"
  },
  "tokenEstimation": {
    "codeCharsPerToken": 3.5,
    "proseCharsPerToken": 4.0,
    "mixedCharsPerToken": 3.75
  },
  "anatomy": {
    "maxFileSizeKb": 500,
    "maxFiles": 2000
  },
  "daemon": {
    "enabled": false,
    "usePM2": false
  }
}
```

### Key Config Options

| Key | Default | Description |
|-----|---------|-------------|
| `dashboardPort` | `18791` | Port for `openwolf dashboard` |
| `exclude` | see above | Directories and files excluded from anatomy scanning |
| `cronSchedules.anatomyScan` | every 6h | Cron expression for automatic anatomy refresh |
| `cronSchedules.cerebrumReflection` | Monday 9am | Weekly AI cerebrum cleanup |
| `anatomy.maxFileSizeKb` | `500` | Skip files larger than this for anatomy |
| `anatomy.maxFiles` | `2000` | Hard cap on number of tracked files |
| `daemon.enabled` | `false` | Enable background daemon on init |
| `daemon.usePM2` | `false` | Use PM2 for daemon process management |

### Adding Exclude Patterns

Add patterns to the `exclude` array to prevent large generated directories from bloating anatomy.md:

```json
{
  "exclude": [
    "node_modules", ".git", "dist", ".next", "build",
    "coverage", ".wolf", "vendor", "__pycache__", ".venv",
    "*.min.js", "*.map"
  ]
}
```

After updating exclude patterns, run `openwolf scan` to regenerate anatomy.md.
